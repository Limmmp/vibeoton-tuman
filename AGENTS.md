## Что это

**«Туман Владивостока»** — проект команды на хакатоне «Вайбатон». Это приложение для досуга и знакомства с Владивостоком. Карта города закрыта туманом и открывается там, где ты был. Поверх карты пять режимов:

- **Приключение** — квесты и персонажи;
- **Компания** — подбор досуга для группы с разными интересами, бюджетами и временем;
- **Места** — бесплатные и недорогие места для учёбы и творчества;
- **История** — аудиоквест, у каждого факта есть источник;
- **Помощник** — для первокурсников, новых жителей и туристов.

Карта с выраженным рельефом: Владивосток стоит на сопках.

Полный диз-док: [docs/design-doc.md](docs/design-doc.md).

## Стек и архитектура

- **Основной продукт — мобильное приложение** React Native + Expo (делает Дима, в репо пока нет). Полный GPS-геймплей, квесты, аудио и группы проектируются прежде всего для телефона.
- **Desktop web — урезанный кабинет:** прогресс, профиль, коллекция, инвентарь, экипировка, магазин, друзья и планирование. Геоквесты и фоновый GPS на desktop не являются целевым сценарием.
- **Карта** — отдельная веб-страница на MapLibre GL 5 (Vite + TypeScript), открывается в приложении через WebView. Нативный MapLibre не умеет 3D-рельеф. Опубликована на https://limmmp.github.io/vibeoton-tuman/ (GitHub Actions, автодеплой при пуше в `main`). Протокол «приложение ↔ карта» — [src/engine/protocol.ts](src/engine/protocol.ts), инструкция — [docs/map-engine.md](docs/map-engine.md).
- **ИИ** — GPTunnel, совместим с API OpenAI: `https://gptunnel.ru/v1`. Бюджет команды 20 000 ₽. **Ключ не коммитить**, репо публичный: ключ только в `.env` (он в `.gitignore`). Организаторы дадут сервер (Docker; правки на сервере вносит один человек).

## Команды

```bash
npm install
npm run dev          # карта + отладочная панель: http://localhost:5173
npm test             # тесты (node:test, TS запускается прямо в Node 24)
npm run typecheck
npm run build
npm run data:fetch   # кандидаты из OSM → data/raw/osm-places.json
npm run data:build   # → data/places.json (verified/manual-записи не трогаются)
npm run data:check
npm run data:audit   # → data/audit.md
node scripts/demo-match.ts [--bad-weather]
```

## Правила

- **Весь пользовательский текст на русском.**
- **Не трогать старый фронт vl-fog** (`D:\Projects\apps\vl-fog`), его переписывает Дима. Из него взята только схема ячеек тумана.
- **Факты и данные не выдумывать.**
  - `verified: true` ставит только человек.
  - У каждого факта и места есть `source`.
  - Допущения пишутся в `notes`.
- **Правки мест — только в `data/manual/overrides.json`**, потом `npm run data:build`. `places.json` руками не править.
- **Ячейки тумана:** ключи `"row:col"` совместимы с vl-fog — не менять схему.
- **Координаты:** поле `lon`, не `lng`. В диз-доке осталось `lng`, это нужно поправить.
- **Никакой украинской и политической символики в интерфейсе.**
- **Коммиты на русском**, осмысленные. Пушить в `main` (сначала `git pull --rebase`).
