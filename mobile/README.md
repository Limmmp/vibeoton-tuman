# Мобильное демо «Туман Владивостока»

React Native, Expo SDK 58, TypeScript. Для Android и iOS нужен Expo Go с поддержкой SDK 58 или development build.
Движок MapLibre остаётся в корневом проекте и работает в WebView; интерфейс приложения — нативный.
Контракт импортируется из `../src/engine/protocol.ts`, без копирования типов.

## Запуск

Нужны Node.js LTS, Expo Go на телефоне и общая Wi-Fi сеть с компьютером.

Первый терминал, из корня репозитория:

```powershell
npm ci
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

Второй терминал:

```powershell
cd mobile
npm ci
npm start
```

Открой QR-код через Expo Go на Android или камеру на iOS.
Адрес карты определяется из LAN-адреса Expo. Кнопка **Адрес** позволяет заменить его вручную.
Проверь доступность `http://<IPv4 компьютера>:5173` в браузере телефона.
IPv4 можно посмотреть командой `ipconfig`. Разреши Node.js доступ к частной сети в брандмауэре Windows.

Альтернатива: скопируй `.env.example` в `.env.local`, задай `EXPO_PUBLIC_MAP_URL` и перезапусти Expo.
Не указывай `localhost` на физическом телефоне: это сам телефон, а не компьютер.
Для Android Emulator можно использовать `http://10.0.2.2:5173`.
Туннель Expo передаёт Metro, но не сервер карты: для удалённого телефона нужен отдельный доступный HTTPS-адрес карты.

Проект обновлён до SDK 58. Если Expo Go сообщает о несовместимом SDK, обнови Expo Go до версии с поддержкой SDK 58.
Инструкция по обновлению SDK: https://docs.expo.dev/workflow/upgrading-expo-sdk-walkthrough/

После обновления проекта останови Metro и выполни из `mobile/`:

```powershell
npm ci
npm start -- --clear
```

Если PowerShell не находит `npm`, добавь Node.js в PATH текущего терминала:

```powershell
$env:Path = "C:\Program Files\nodejs;$env:Path"
npm.cmd start -- --clear
```

## Проверка демо

1. Дождись карты и статуса «Демопрогулка».
2. Нажми на свободную точку карты: игрок идёт к ней, туман открывается, площадь растёт.
3. Включи 3D, проверь наклон и рельеф. «Где я» возвращает слежение за игроком.
4. Выбери одно из трёх мест. «В демо-точку» переносит игрока туда без GPS.
5. Нажми «Маршрут сюда» или удерживай точку карты. После ответа появятся линия, расстояние, подъём, спуск и время.
6. Включи GPS и выдай разрешение. Карта получает реальные координаты, даже если ты находишься вне Владивостока.
7. Выключи GPS, чтобы вернуться к симуляции. При отказе в разрешении демо продолжает работать.
8. Перезапусти приложение с тем же адресом карты: открытый туман должен сохраниться в WebView.
9. Останови сервер карты и переподключись: приложение показывает ошибку и позволяет исправить адрес.

Сброс тумана требует подтверждения. «Убрать маршрут» удаляет линию и её сводку.

```powershell
npm run typecheck
npx expo install --check
npx expo export --platform android --output-dir dist-android
npx expo export --platform ios --output-dir dist-ios
```

## Границы демо

- Нужен интернет для тайлов, рельефа и сервиса пеших маршрутов OSRM. Офлайн-карты не реализованы.
- GPS работает только при открытом приложении. Фоновой геолокации и серверной синхронизации нет.
- Прогресс хранится локально по адресу карты. При смене IP/порта или очистке данных WebView он может стать недоступен.
- Места — демонстрационные точки; каталога, авторизации и остальных режимов приложения пока нет.
- Высоты имеют ограничения, описанные в `../docs/map-engine.md`, особенно на мостах.
- WebView предназначен для Android/iOS. Для браузерной проверки используй корневой `npm run dev`; Expo Web в этом демо не настроен.
- HTTP разрешён для локального тестирования. Для публикации приложения нужен HTTPS-сервер движка.

## Результаты проверки

После обновления до Expo 58.0.25 проверены TypeScript, совместимость установленных модулей SDK 58 и экспорт JavaScript/Hermes-бандлов Android и iOS. `expo-doctor`: 20/20 проверок пройдено.
Движок карты собран командой `npx vite build --configLoader runner` (стандартный загрузчик конфигурации ограничен файловой песочницей среды разработки).
Экспорты не являются APK/IPA. Проверка на реальном телефоне, включая WebGL, GPS и жесты, ещё требуется.

`npm audit` также сообщает об уязвимостях зависимостей: critical в существующем MapLibre и moderate в цепочке Expo/minimatch.
На момент проверки audit не предложил исправления без смены зависимостей для всей цепочки.
Перед публичным выпуском нужно повторить аудит и проверить обновления. Принудительное обновление с нарушением совместимости SDK не выполнялось.
