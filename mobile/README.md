# Мобильное приложение «Туман Владивостока»

React Native + Expo SDK 58.0.25. Интерфейс приложения — нативный, карта MapLibre постоянно работает в WebView под шторками.

## Запуск на телефоне

Нужны Node.js LTS и Expo Go с поддержкой SDK 58. По умолчанию используется опубликованная HTTPS-карта https://limmmp.github.io/vibeoton-tuman/; локальный сервер карты запускать не обязательно. Metro для приложения запускается отдельно.

Для разработки локального движка: телефон и компьютер должны находиться в одной Wi-Fi сети. Первый терминал, из корня `vibeoton-tuman`:

```powershell
npm ci
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

Второй терминал, из того же корня:

```powershell
cd mobile
npm ci
npm start -- --clear
```

Открой QR-код через Expo Go на Android или камеру на iOS. При несовместимом SDK обнови Expo Go либо используй development build SDK 58.

Если PowerShell не видит Node.js, выполни в каждом терминале:

```powershell
$env:Path = "C:\Program Files\nodejs;$env:Path"
```

Для локальной карты задай `EXPO_PUBLIC_MAP_SOURCE=local` в `.env.local`: адрес определится по LAN-адресу Expo. Чтобы изменить адрес вручную, открой **Профиль → Настройки**. Сохранённый адрес в настройках имеет приоритет при следующем запуске.
Можно указать `http://<IPv4 компьютера>:5173` или выбрать опубликованную карту. IPv4 виден в `ipconfig`.
На физическом телефоне `localhost` означает сам телефон. Для Android Emulator используй `http://10.0.2.2:5173`.
Проверь URL в браузере телефона и разреши Node.js доступ к частной сети в брандмауэре Windows.

Для постоянного адреса скопируй `.env.example` в `.env.local`, измени `EXPO_PUBLIC_MAP_URL` и перезапусти Metro.
Туннель Expo передаёт Metro, но не сервер Vite. Опубликованная карта должна содержать актуальный квестовый протокол.

## Что реализовано

- Онбординг: роль, интересы, объяснение GPS, отказ с переходом в симуляцию. Настройки сохраняются локально.
- Постоянная карта, пять увеличенных вкладок, шторка с тремя положениями. Высота меняется свайпом за ручку; профиль выбирается вкладкой и разворачивается свайпом вверх.
- HUD: уровень, опыт, открытая площадь, погода в центре Владивостока. Тёмная тема, Manrope и Russo One.
- Слои карты, 2D/3D, слежение за игроком, GPS, симуляция, ошибки подключения и плашка отсутствия сети.
- Мост: типизированные команды, очередь до `ready`, промисы по `id`, таймауты и отмена при переподключении.
- Каталог из `data/places.json`: поиск, фильтры, карточки, источники, статус проверки, подпись OpenStreetMap.
- Пешие маршруты, время, подъём/спуск и мини-профиль высот.
- Квесты: доступные, активные, пройденные; запуск, остановка с подтверждением, повтор после провала.
- Все девять типов шагов: goto, hold, tail, collect, explore, listen, quiz, look, visit.
- Награды по событиям движка. Симуляция и телепорт не начисляют награду. UI не меняет опыт или валюту самостоятельно.
- Профиль: опыт, монеты, уважение, пройденные квесты, инвентарь, экипировка с обновлением аватара на карте.
- Компания: последовательные анкеты, сохранение участников и черновика, общее окно времени, `matchGroup`, три результата, голосование по участникам и отправка плана.
- Помощник: локальный демонстрационный чек-лист по роли. Уведомления: плашки и история событий сессии.
- Отдельная панель разработчика с живыми данными движка.

## Проверка панели разработчика

1. Пройди онбординг. Для теста выбери симуляцию.
2. Открой **Профиль → Для разработчиков**.
3. Нажми **«Короткий тест: аудио → quiz → осмотр»**. Это технический квест без исторических утверждений.
4. Проверь активный шаг: тип, текст, расстояние, прогресс и `runtime`.
5. На шаге аудио нажми **«Телепорт к цели»**. Кнопка **«Аудио дослушано»** станет доступна после `audioReady`.
6. Нажми **«Аудио дослушано»**. Это имитация окончания аудио только в панели разработчика.
7. Выбери неправильный ответ quiz: шаг должен остаться активным. Затем выбери «Подтвердить осмотр».
8. На шаге look нажми **«Подтвердить осмотр»**. Если игрок вне зоны, сначала вернись к цели.
9. Экран результата должен сообщить **«Демо-режим: награда не выдана»**. Опыт и монеты не должны увеличиться.
10. Закрой результат, снова открой панель и проверь **«Статус награды»**.

Полный квест движка запускается кнопкой **«Запустить квест»** в его карточке. Для перемещения по симуляции закрой панель и нажимай на карту.
В панели можно телепортироваться к каждой следующей цели; шаг hold требует постоять в зоне указанное число секунд.
Для проверки настоящей награды включи GPS **до** запуска каталожного квеста и пройди его без симуляции или телепорта.

## Аудио и честность прохождения

`demo://quest-audio` — заглушка движка, не аудиофайл. Обычный интерфейс не позволяет дослушать несуществующую запись.
Для HTTP(S)-аудио подключён `expo-audio`: воспроизведение в радиусе точки, пауза и подтверждение после конца записи.
Внешние аудиофайлы и историческая озвучка ещё не добавлены. Разрешение микрофона и фоновая запись не запрашиваются.
Геопроверки, правильность quiz и начисление наград остаются на стороне движка карты.

## Ограничения и внешние данные

- «Золотой туман», исторические факты, иллюстрации, фото, персонажи и фигурки ждут данных/ассетов. Экран истории показывает это явно.
- ИИ-чат, группы по QR, пуши, социальная видимость и чекин с наградой ждут сервера/команд. Магазин не списывает монеты и не имитирует покупки.
- Нет фонового GPS и полноценного офлайн-режима. Наличие старых тайлов в WebView не гарантирует доступность карты без сети.
- Проценты районов доступны в профиле через «Районы и вехи»; это доля открытых уличных ячеек, не всей географической площади.
- Помощник использует явно отмеченный демонстрационный чек-лист, а не утверждённую базу задач.
- «Без подъёма» показывает только места с уже рассчитанным маршрутом и подъёмом до 40 м. Неизвестные высоты не выдаются за нулевые. Кэш очищается при перемещении более чем на 50 м.
- Каталог не изменяется приложением. Неизвестные часы и цены не выдаются за подтверждённые. Условия следует проверять по источнику.
- Погода запрашивается у Open-Meteo для фиксированного центра города, а не координат игрока. При ошибке отображается «нет данных» и доступен ручной фильтр помещений.
- Начальная и конечная точки маршрута передаются существующим движком сервису OSRM. Передачи позиции другим игрокам нет.
- Прогресс квестов, инвентарь и туман хранятся в WebView по адресу карты. Настройки, интересы и анкеты — в AsyncStorage приложения. Смена адреса карты может открыть другое хранилище.
- HTTP разрешён для локального теста; для публикации нужен HTTPS.

## Проверки разработчика

```powershell
npm run typecheck
npm test
npx expo-doctor
npx expo export --platform android --output-dir dist-android
npx expo export --platform ios --output-dir dist-ios
```

Тесты мобильной части проверяют очередь/ответы моста, таймауты, переподключение и прохождение диагностического квеста через команды с геопроверками, неверным quiz и отказом в демо-награде.
Корневой `npm test` проверяет квестовый движок, прогресс и подбор компании.
Экспорт бандла не является сборкой APK/IPA. WebGL, GPS, аудио, жесты и размеры экранов требуют проверки на телефоне.
Expo Web не настроен: браузерное демо карты запускается корневым `npm run dev`.

Схема экранов: `../docs/screens.md`; функции: `../docs/features.md`.

## Дополнения по новым контрактам

- «Профиль → Районы и вехи»: `getDistricts`, живое обновление через `districtProgress`, уведомления `districtMilestone`.
- «Места → карточка → Я здесь»: сначала регистрация места в `showPlaces`, затем `checkIn`; расстояние и первая награда проверяются движком. В пользовательском интерфейсе требуется GPS.
- Экран награды различает квест, чекин и веху района через `RewardResult.source`.
- «Настройки»: экономный, сбалансированный и высокий профиль через `setRenderQuality`. Полученный профиль обновляется через `renderQualityChanged`. Pixel ratio полностью обновляется после перезагрузки карты.
- По умолчанию показываются до пяти ближайших стартов квестов. Категории мест включаются вручную, до 15 меток. Это ограничение фронта, не кластеризация движка.
- «Настройки → Сравнить стили и темы»: отдельный пробник HUD / стиля Макса, светлой / тёмной / системной темы на шапке, шаге и награде. Глобальная тема приложения пока остаётся тёмной; пробник не выдаётся за завершённую смену темы всего приложения.

`frontend-vision.md` содержит и проект будущей архитектуры. Миграция на Expo Router, Gorhom, Reanimated, Zustand, глобальные токены и темы ещё не выполнена: сохранены рабочие навигация и жесты текущего демо.
`setLayers`, `setMapTheme`, социальные аватары, кластеры и объёмные эффекты из `map-visuals.md` пока описаны как план и отсутствуют в текущем `Command`. Интерфейс не отправляет несуществующие команды и использует `showPlaces`.

## Компактный интерфейс и иконки

### Возврат между экранами

В шапке карты есть кнопка возврата, во вложенных окнах — «Назад» и отдельная кнопка «Закрыть».
«Назад» проходит историю переходов: например, панель разработчика → настройки → меню → исходная вкладка.
Возвращаются выбранное место, слой карты и положение шторки. Переход «На карте» также сохраняет исходный экран для возврата.
«Закрыть» убирает всю цепочку вложенных окон. После награды «Продолжить» возвращает к открытому до неё окну.
Системная кнопка Android использует тот же возврат; на корневой карте сначала сворачивает открытую шторку, затем отдаёт управление системе.
Свайпы шторки не создают новые записи в истории. Карта при возврате не перезагружается.

Слои карты доступны через ☰ в шапке. Фильтры каталога скрыты под кнопкой «☰ Фильтры».
Используются PNG из `public/images`; Metro включает их в приложение через статические `require`.
Для компании, профиля, меню и уведомлений пока используются временные текстовые значки. Нужны отдельные иконки этих четырёх действий в общем стиле, желательно PNG @2x/@3x с прозрачным фоном.

Шторка имеет постоянный размер и перемещается через `Animated` без изменения размеров карты. Содержимое не размонтируется при сворачивании.
WebView вынесен в мемоизированный компонент. Одинаковые наборы меток не отправляются повторно при каждом движении игрока.
Уведомления появляются и исчезают поверх карты без сдвига интерфейса. Окна используют переходы и плавное появление содержимого; учтена системная настройка уменьшения движения для пользовательских анимаций.
Плавность жестов и читаемость новых размеров нужно проверить на реальном телефоне; показатели FPS не измерялись.

API: https://docs.expo.dev/versions/v58.0.0/sdk/audio/ и https://open-meteo.com/en/docs.
`npm audit` сообщает о moderate в цепочке Expo/minimatch и critical в существующем MapLibre. Перед публичным выпуском нужен повторный аудит зависимостей.
