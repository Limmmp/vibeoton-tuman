# Модели достопримечательностей

Положите сюда свои файлы с точными именами:

| Файл | Достопримечательность |
| --- | --- |
| `s56.glb` | Подлодка С-56 |
| `lighthouse.glb` | Токаревский маяк |
| `bridge.glb` | Золотой мост |
| `funicular.glb` | Фуникулёр |

Пока GLB-файла нет или он повреждён, показывается геометрическая заглушка. После добавления корректного файла загрузчик автоматически использует модель на карте и в коллекции. Исходный код менять не нужно.

Экспорт из Blender: glTF 2.0 → GLB, включить материалы и текстуры, применить трансформации. Рекомендуются до 2 МБ, до 10 тысяч треугольников и текстуры до 1024×1024. Ограничение загрузчика — 20 МБ. Поддерживается обычный GLB без Draco/KTX2; для сжатых файлов сначала экспортируйте несжатую версию. Y — вверх. Viewer автоматически центрирует модель и нормирует её габарит, поэтому исходные единицы не обязаны быть метрами.

Положение на карте задаётся в `manifest.json`:

- `lat`, `lon` — точка размещения;
- `mapSizeMeters` — длина максимальной стороны фигурки на карте;
- `rotationDegrees` — поворот вокруг вертикальной оси;
- `altitudeMeters` — дополнительная высота над рельефом.

Масштаб на карте — демонстрационный. Особенно для моста: это фигурка у точки интереса, не замена дорожной геометрии во всём пролёте. Координаты и поворот требуют визуальной калибровки с вашей моделью. Источники и ограничения точек записаны в `source` и `notes`; `verified: true` ставит только человек.

Проверка локально: `npm run dev`, открыть `/collection.html`, выбрать модель. На карте включить «Баланс» или «Высокое» и 3D, открыть туман у достопримечательности. В `low` остаются плоские метки.

Для постоянной версии добавьте GLB в Git, выполните `git pull --rebase` и отправьте изменения в `main`. GitHub Actions публикует содержимое `public/` автоматически. Затем переподключите карту с новой меткой `?v=...`, чтобы обновить кэш моделей. Пересборка APK для замены GLB не нужна.
