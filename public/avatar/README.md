# Аватар игрока

Аватар всегда является 2D-картинкой в DOM поверх карты. Он стоит над указателем координаты, не наклоняется вместе с камерой и не вращается вслед за курсом. Вращается только указатель под картинкой.

Для замены положите `avatar.png` (или SVG/WebP/GIF) в эту папку и измените `config.json`:

```json
{
  "idle": "avatar.png",
  "moving": null
}
```

Для будущей анимации положите рядом `walk.gif` и установите `"moving": "walk.gif"`. При движении включится GIF, через 250 мс после остановки вернётся `idle`. Если `moving` пустой, используется только статичная картинка. Размеры желательно 96×112 или с близкими пропорциями, с прозрачным фоном. На карте изображение вписывается в 52×64 CSS-пикселя.

После публикации файлов и настройки в `main` переподключите карту с новой меткой `?v=...`. Для замены картинки пересборка APK не нужна. Поля экипировки профиля сохраняются, но отдельные шапки и одежда поверх готового изображения не рисуются. Старое поле `modelUrl` не используется для аватара; 3D-аватар не загружается.
