# Ветка `polish/demo-focus`: что сделано и что осталось

Ветка отходит от `main` (коммит `0252c27`) и **в `main` не слита**. `main` автоматически выкатывается на GitHub Pages, поэтому новая карта появится на телефонах только после слияния. Решение о слиянии — за командой.

Как проверить ветку у себя:

```bash
git fetch origin && git switch polish/demo-focus
npm ci --include=dev && npm run dev -- --host 0.0.0.0 --port 5173 --strictPort   # карта
cd mobile && npm ci && npm start -- --clear                                      # приложение
```

В приложении: Профиль → Настройки → «Локальная карта». Опубликованная карта собирается из `main` и новых изменений не содержит.

## Сделано

### Продукт и маршруты
- **Пологий маршрут.** Суммарный подъём во Владивостоке почти неизбежен (точки на разной высоте), поэтому пологий вариант выбирается по метрам пути круче 12% и самому крутому месту. Кандидаты: альтернативы OSRM и объезды через точки по бокам от середины пути. Пример для защиты: Спортивная → Тигровая — короткий путь 300 м крутизны с пиком 30%, пологий +3 минуты, 100 м крутизны и пик 19%. Код: `src/engine/route.ts`, `src/engine/route-pick.ts` (+ тесты); в приложении — переключатель «Короткий / Пологий».
- **«Без крутых подъёмов» больше не обнуляет подбор.** Раньше учитывались только места с уже построенным маршрутом.

### Дизайн (скиллы `apple-design`, `animate-expo`)
- **Дизайн-система «Туман»** (`mobile/src/ui.tsx`): ночной фон, слои поверхностей, янтарь как единственный акцент, Manrope с трекингом по размеру.
- **Каркас:** плавающая плашка «уровень + открытая площадь», четыре вкладки с SVG-иконками (Карта · Куда пойдём · Места · Профиль).
- **Убрано из интерфейса:** гача, гардероб, магазин-заглушка, пустая «История», отладка. Движок всё это по-прежнему поддерживает. Панель разработчика и демо-перемещение открываются **долгим нажатием на значок уровня**.
- **Единый набор иконок** (`mobile/src/glyphs.tsx`) и 10 образов для аватаров: маяк, чайка, якорь, волна, сопка, кот, тигр, звезда, мост, компас.

### Карта
- **Ночная тема подложки** (`src/engine/dark-style.ts` + тесты). Палитра `prepareMapStyle` и её тест не тронуты.
- **Туман непрозрачный и лежит поверх подписей:** под ним не видно ни улиц, ни рельефа. Отмывка сопок — под туманом.
- **Игрок** — янтарная стрелка со свечением. Спрайт `public/avatar/Schoolboy.gif` — стоковая картинка с водяным знаком, он скрыт, использовать его нельзя.
- **Метки мест** — значки в стиле иконок приложения (`src/engine/pins.ts`).

### 3D-фигурки
- Все четыре пересобраны в Blender в едином стиле (тёмный постамент с янтарной кромкой), детали сверены с фото на Wikimedia Commons: С-56, фуникулёр, маяк Токаревского, Золотой мост.
- Сборка одной командой: `tools/models/build.sh [s56,funicular,lighthouse,bridge]` (Blender 5 в фоне). Превью для слайдов — `tools/models/previews/`.

### Бэкенд (`server/`, контракт — `docs/backend-api.md`)
- Node 24 + TypeScript без сборки, Hono, встроенный SQLite. Работает на сервере хакатона: **`https://176-53-248-123.sslip.io`** (Docker + Caddy, HTTPS через Let's Encrypt; код в `/opt/tuman`, ветка `polish/demo-focus`).
- **Вход:** почта и пароль (scrypt), VK ID, Telegram, Яндекс, Google — каждая соцсеть включается своим ключом в `deploy/.env`. Демо-вход по имени (`DEV_LOGIN=1`) с друзьями Петей, Машей и Аней (`SEED_DEMO=1`).
- **Друзья** по коду или нику, **пачки** — постоянные компании.
- **Встречи с тремя режимами бюджета:** каждый за себя / скидываемся (общий котёл) / одна сумма для всех с подсказкой, кому не хватает. Свою сумму видит только сам участник.
- **Подбор мест** тем же `matchGroup`, голосование, выбор места.
- **16 тестов.** Закрыты две уязвимости, найденные автопроверкой: токен Яндекса чужого приложения и склейка аккаунтов по почте.

### Приложение: аккаунт и встречи
- Экран входа, профиль с редактором аватара, код друга, заявки, друзья, пачки (`AuthScreen`, `FriendsPanel`).
- «Куда пойдём» — встречи (`MeetingsPanel`): позвать друзей или пачку, выбрать режим бюджета, ответить «иду» со своей суммой и пожеланиями, подобрать места, проголосовать, выбрать место, построить маршрут. Без аккаунта остаётся прежний быстрый подбор.
- Весь путь проверен против боевого сервера.

### Анимации (Reanimated, Gesture Handler, Haptics — всё входит в Expo Go)
- **Шторка на UI-потоке:** ведётся пальцем 1:1, точка остановки по инерции, скорость передаётся пружине, мягкое сопротивление у краёв, тап по ручке переключает положения, вибрация при защёлкивании.
- **Нажатия** — плавное сжатие за 120 мс; чипы дают тактильный щелчок выбора.
- **Появление:** списки встреч и результатов подбора выплывают лесенкой, уведомления въезжают сверху, награда — мягкое увеличение с вибрацией успеха.
- Вкладки без анимации (их переключают десятки раз). Системное «уменьшить движение» учитывается.

### Вход через соцсети
Сервер готов, но нужны ключи. Их регистрирует владелец аккаунтов:
- VK ID — приложение на id.vk.com → `VK_CLIENT_ID`;
- Telegram — бот через @BotFather, `/setdomain` → `TELEGRAM_BOT_TOKEN`;
- Яндекс ID — приложение на oauth.yandex.ru → `YANDEX_CLIENT_ID`;
- Google — OAuth-клиент → `GOOGLE_CLIENT_IDS`.

Ключи вписываются в `deploy/.env` на сервере, после чего контейнер перезапускается. В приложении остаётся сделать вход через браузер (`expo-auth-session`) и передать полученный токен на `/auth/<провайдер>` — сейчас кнопки соцсетей неактивны.
