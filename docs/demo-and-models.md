# Демо-перемещение и коллекция

В приложении: меню карты → «Демо-перемещение». В обычном браузере: кнопка «Демо и коллекция» справа сверху.

Если установленный APK ещё без нового меню, добавьте `&demo=1` к адресу карты: панель появится внутри WebView. Для полноценного нового меню нужен свежий JS-бандл Expo или пересборка APK.

Телепортация доступна нажатием на пустую область карты, по координатам или кнопкой достопримечательности. Долгое нажатие в приложении также предлагает телепортацию. GPS перед демо отключается. Старая цель движения сбрасывается; туман открывается только у точки назначения, без коридора через весь город.

Для ускоренной прогулки выберите ×1, ×8 или ×32 и режим «Идти к точке». Множитель влияет на движение симуляции, не добавляет ускорение таймеров квестов. Обычный GPS не ускоряется. Для возврата к реальному местоположению включите GPS в настройках.

После перехода в симуляцию движок игнорирует запоздалые `gpsFix`; они принимаются только в `external`. Панель внутри старого APK не может остановить его нативную GPS-подписку, поэтому там GPS лучше выключить вручную. Позицию персонажа такие фиксы в демо не перезаписывают.

Команды движка:

- `setPlayerMode { mode: "sim" }` — перед демо;
- `setDemoTapMode { mode: "walk" | "teleport" }` — действие нажатия на пустой карте;
- `setSimSpeed { multiplier: 1..64 }` — скорость симуляции; интерфейс предлагает 1, 8, 32;
- `teleport { lat, lon }` — перенос и остановка предыдущего пути;
- `walkTo { lat, lon }` — движение к точке.

Состояние: `player.simSpeed`, `demoTapMode`. Событие `demoChanged` синхронизирует элементы управления. Метка достопримечательности отправляет `landmarkTap { id }`, приложение открывает соответствующую фигурку.

Коллекция доступна из профиля и меню карты, а также напрямую по `/collection.html`. Все четыре фигурки открыты как демонстрационные превью; это не покупка и не выдача игровой награды. Одна модель загружается в viewer за раз. Вращение и приближение — мышью или жестами. Непрерывного цикла вращения нет: viewer рисует кадр по взаимодействию, загрузке и изменению размера. При закрытии WebView освобождается.

На карте GLB и Three.js подключаются по требованию в 3D на `balanced/high`. Модель видна только в открытой ячейке, при zoom ≥ 14 и расстоянии камеры менее 2 км. Одновременно в каталоге не больше четырёх объектов. В `low` остаются плоские метки; при переходе на `low` ресурсы 3D-моделей освобождаются.

Место для загрузки и параметры моделей: [public/models/landmarks/README.md](../public/models/landmarks/README.md). После изменения интерфейса Expo нужно перезагрузить приложение; после замены самих GLB пересборка приложения не требуется.


В радиусе `buildingClearanceMeters` вокруг загруженной фигурки исключается процедурная 3D-геометрия зданий. Радиус задаётся индивидуально в манифесте; проверяются контуры и рёбра, а не только первая вершина. Картинка игрока и будущая GIF-анимация настраиваются в [public/avatar/config.json](../public/avatar/config.json), инструкция — [public/avatar/README.md](../public/avatar/README.md).
