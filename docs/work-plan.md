# Общий план работ

Актуально на 13 ноября 2026. Основание: [аудит проекта](audit-2026-11-13.md), `docs/features.md`, `docs/screens.md` и последние коммиты front v1.1 / backend.

## Цель MVP

Полный мобильный сценарий на Samsung Galaxy A24:

1. пользователь проходит онбординг;
2. карта получает GPS и открывает туман;
3. пользователь запускает сюжетный квест;
4. интерфейс проводит через геошаги, аудио, вопрос и осмотр;
5. квест выдаёт опыт и предмет;
6. предмет надевается на аватар;
7. прогресс, туман и активный квест восстанавливаются после перезапуска;
8. режим «Компания» подбирает место группе;
9. режим «Места» показывает полезный проверенный каталог.
