# Фичи фронта (React Native + Expo)

Полный список того, что должно уметь приложение. В [screens.md](screens.md) расписано, **где** это на экране; здесь — **что** сделать, откуда брать данные и готова ли под это сторона карты и данных.

Колонки:
- **Приоритет:** **MVP** — нужно к демо, **потом** — после хакатона или если останется время.
- **Готовность:**
  - «есть» — команда или данные уже есть в движке и репо;
  - «частично» — есть основа, нужна доработка;
  - «нет» — нужен бэкенд или новые данные, вопрос к капитану.
- **Контракт:** команды и события моста — `src/engine/protocol.ts`, типы квестов — `src/quests/types.ts`, прогресса — `src/progress/types.ts`.

Стартовая точка — демо-приложение в `mobile/` (`App.tsx`, `src/connection.ts`, `src/places.ts`).

## Сквозные требования

- **Ключи ИИ никогда не попадают в приложение.** Все запросы к GPTunnel идут через прокси на нашем сервере. Ключ, зашитый в приложение, достаётся из сборки за минуты.
- **Точная позиция игрока никуда не уходит,** пока нет группы с подтверждёнными участниками.
- **Производительность:** на телефонах профиль `low` по умолчанию; 3D оставляет рельеф, но отключает дома. Пользователь может выбрать `balanced` или `high`. Профиль карта отдаёт в `renderProfile`.
- **Доступность:** масштабирование шрифтов, контраст на тёмной теме, подписи для экранного диктора у кнопок-иконок.
- **Весь текст на русском.** В интерфейсе нет украинской и политической символики.
- **Пустые состояния, загрузка, ошибки, офлайн** — на каждом экране (screens.md, раздел «Состояния»).

2. **Команда списания монет и логика гачи** в модуле прогресса.
3. ~~Команда чекина в месте~~ — готово (`checkIn`).
4. ~~Районы в новом движке~~ — готово (`getDistricts`, вехи с наградами).
5. **Маршрут «Золотой туман»:** шаги, `facts.json` с источниками, аудио.
6. **Список пунктов чек-листа помощника** для трёх типов пользователей.
7. **Бэкенд групп** (если будет сервер): QR, WebSocket, видимость.
