# Подбор досуга для компании (`matchGroup`)

Чистая функция без сети и без карты: [`src/match/matchGroup.ts`](../src/match/matchGroup.ts). Её можно импортировать в приложение (React Native) или вызвать на сервере. Логика описана в диз-доке, раздел 5.

## Как вызвать

```ts
import { matchGroup } from "../src/match/matchGroup";
import places from "../data/places.json";

const win = { start: "2026-11-13T18:00:00+10:00", end: "2026-11-13T22:00:00+10:00" };
const out = matchGroup({
  members: [
    { name: "Аня", interests: ["boardgames", "coffee"], budget: 300, window: win, from: { lat: 43.0245, lon: 131.8925 } },
    { name: "Петя", interests: ["sea", "views"], budget: 1500, window: win, noClimb: true },
  ],
  places,
  weather: { bad: true },              // туман/дождь → только в помещении
  climbOf: (p) => climbs[p.id],        // необязательно: подъём до места из движка карты
  isNew: (p) => !fogRevealed(p),       // необязательно: бонус местам под туманом
});
// out.window  — общее свободное время (или null)
// out.results — до 3 вариантов: { place, event?, score, price, travel, flags, reason, perMember }
// out.hints   — если вариантов мало: «Если поднять бюджет до 450 ₽, появится ещё 3 варианта»
```

## Что внутри

1. **Жёсткие фильтры.**
   - Цена не выше минимального бюджета в компании. Если цена неизвестна, а кто-то хочет «только бесплатно», место отсеивается.
   - Общее окно свободного времени минус дорога: на месте должно остаться ≥ 60 минут (`minStayMin`). Событие должно поместиться целиком.
   - Место открыто по часам работы (часовой пояс Владивостока).
   - Плохая погода → только места с тегом `indoor`.
   - «Без крутых подъёмов» → отсеиваются места с подъёмом больше 40 м, если передан `climbOf`.
2. **Оценка.**
   - Каждому участнику считается совпадение с его интересами: один интерес — 0,5, два — 1.
   - Итог = минимум × 0,6 + среднее × 0,4, чтобы никому не было совсем скучно.
   - Бонусы: место под туманом +0,1, настроение (спокойно / активно) +0,05.
   - Штрафы: цена неизвестна −0,1, часы неизвестны −0,05, дорога дольше 30 минут — около −0,1 за час.
3. **Разнообразие.** В топ-3 попадают места разных типов, и по возможности одно из них бесплатное.
4. **Причина «почему вам»** собирается по шаблону: «Аня — настолки и кофе, Маша — кино; по карману всем (250 ₽)». Места выбирает только код, ИИ может лишь переписать текст причины.
5. **Подсказки,** если вариантов меньше трёх: бюджет, погода, время, подъёмы.

Интересы (чипы анкеты) — `INTERESTS` в том же файле: `sea`, `views`, `nature`, `history`, `culture`, `art`, `music`, `cinema`, `boardgames`, `coffee`, `food`, `sport`, `study`.

Дорога пока считается грубо: 10 минут ожидания + 3,5 минуты на каждый км по прямой. Это транспорт по городу, не пешком.

## Что пока мешает

**Алгоритм упирается в данные.** В каталоге из OSM почти нет тегов-интересов (`board-games`, `sea`, `cinema`) и почти нет цен. Поэтому место обычно совпадает с интересами только одного человека, и очки низкие. Нужно дозаполнить теги и цены хотя бы у 50 мест для демо.
