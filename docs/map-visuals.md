# Визуал карты: аватары, туман, дома

План, как сделать карту красивой и не шумной. Обсудили с капитаном, ещё не реализовано. Интерфейс вокруг карты — в [frontend-vision.md](frontend-vision.md).

**Цель:** карта выглядит «чудно» в своём стиле. Много игроков не превращают её в кашу. Дома — не серые кирпичи, а ночной портовый город.

## 3D-аватары

**Проблема.** Полноценные 3D-аватары от Макса при большом числе игроков будут теряться, наслаиваться и тормозить.

### Масштаб

- **Фиксированный экранный размер.** Аватар всегда 32–44 px на экране, при любом зуме. Модель не превращается в точку при отдалении и не закрывает квартал при приближении.
- **Свой аватар** чуть крупнее остальных (44 px) и всегда рисуется поверх.

### Уровни детализации по зуму

| Зум | Что видно |
| --- | --- |
| < 14 | только кластеры: кружок с числом («+12») и зоны активности |
| 14–17 | 2D-значки с портретом / цветом аватара |
| ≥ 17 | 3D-модели, но не больше 8–10 на экране; остальные — 2D-значками |

### Наслоение

- **Кластеры.** Аватары ближе ~40 px друг к другу на экране склеиваются в один кластер с числом.
- **Веер.** Тап по кластеру раскладывает аватаров веером вокруг точки.
- **Приоритет отрисовки и яркости:** я → группа → друзья → публичные игроки.
- **Подписи** (имя) — только по тапу.
- **Видимость** — слой фильтруется режимами `off` / `party` / `friends` / `all` (диз-док, 8.5).

### Технически

- **deck.gl `ScenegraphLayer` в режиме interleaved с MapLibre:**
  - рисует glTF-модели;
  - `sizeMinPixels` / `sizeMaxPixels` дают фиксированный экранный размер;
  - есть поворот модели по направлению движения.
- **Альтернатива:** свой custom layer на three.js, если deck.gl окажется тяжёлым (+~500 КБ к бандлу).
- **Кластеры** — `supercluster` по экранным координатам.
- **Слабые телефоны** (`renderProfile.quality === "low"`) — только 2D-значки, без 3D-моделей.

### Требования к модели (для Макса)

- **Модульный аватар:** голова, верх, низ, аксессуар — отдельные части на **общем скелете**. Части соответствуют слотам инвентаря (`AvatarSlot`).
- **До ~5 000 треугольников** на собранного аватара.
- **Одна текстура 512×512** (атлас).
- **Анимации:** «стоит» (idle) и «идёт» (walk), зацикленные.
- **Формат:** `.glb`, точка опоры — между ступнями, Y вверх, рост ≈ 1 единица.
- **Читаемость:** силуэт узнаётся в 40 px — крупная голова, контрастный верх.

## 3D-туман

**Настоящий объёмный туман** (raymarching по объёму) телефоны не потянут. Делаем дёшево, но эффектно:

1. **Туман на земле, как сейчас, но «дышит».** Шумовая текстура медленно плывёт: canvas-источник перерисовывается со смещением шума раз в ~100 мс. На слабых телефонах туман статичный.
2. **Стена тумана на границе.** Вдоль границы открытой области стоят облачка-спрайты: полупрозрачные billboard-картинки на высоте 10–40 м.
   - Ставим их только в кадре, не больше ~150 штук.
   - Облачка медленно колышутся.
   - Издалека и при наклоне камеры это выглядит как стена тумана, из которой выходишь.
3. **Дымка у горизонта** — уже есть (`setSky`).
4. **Рассеивание.** Когда открывается новая область, облачка на её месте плавно тают (0,5–1 с), а не исчезают мгновенно.

**Технически:** custom layer на three.js с инстансингом спрайтов или `IconLayer` / `ScenegraphLayer` deck.gl — тем же слоем, что и аватары.

## Дома

Средствами MapLibre `fill-extrusion`, без своих моделей:

- **Окна.** Текстура окон через `fill-extrusion-pattern` (картинка из спрайта). Ночью окна тёплые, светятся янтарём — «ночной портовый город». Днём — холодные.
- **Цвет по высоте:** низкие дома темнее, высотки светлее, плюс вертикальный градиент (`fill-extrusion-vertical-gradient`).
- **Свет** — `map.setLight`. Направление и цвет можно привязать ко времени суток во Владивостоке: тёплый вечерний и холодный утренний.
- **Знаковые места** — 3D-модели Макса вместо выдавленных кубиков: Токаревский маяк, Золотой мост, фуникулёр, С-56. Ставятся тем же 3D-слоем, что и аватары.
- **Дома только в открытой области** — уже сделано.

## Метки на карте

- **По умолчанию на карте только игрок, ближайшие задания и туман.**
- **Категории** (досуг, учёба, история, события) показываются, только когда выбраны в меню «Слои». Состояние слоёв приходит из интерфейса командой моста `setLayers`.
- **При отдалении метки собираются в кластеры, подписи — по тапу.**

## Новые команды моста (план)

| Команда | Что делает |
| --- | --- |
| `setLayers { layers: ("quests" \| "study" \| "leisure" \| "history" \| "events")[] }` | какие категории меток видны — **готово** |
| `showPlayers { players }`, `updatePlayers`, `removePlayers` | другие игроки (диз-док, 8.5) |
| `setSocialLayer { mode: "off" \| "party" \| "friends" \| "all" }` | фильтр игроков |
| `setMapTheme { theme: "light" \| "dark" }` | светлый стиль карты, если понадобится (frontend-vision.md) |

## Порядок работ (движок)

1. ~~**Метки:** `setLayers`, кластеры, подписи по тапу~~ — готово.
2. ~~**Дома:** окна, цвет по высоте, свет~~ — готово (`setLighting`), текстура окон пока кодом.
3. **Аватары:** 2D-значки + кластеры, затем 3D-слой с уровнями детализации.
4. **Туман:** «дыхание», затем облачка на границе.
5. **Знаковые места** — когда будут модели Макса.
