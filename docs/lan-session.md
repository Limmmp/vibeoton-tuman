# Общая карта в локальной сети

На компьютере в корне репозитория запустите:

```powershell
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

Подключите телефоны к одной Wi-Fi сети. В настройках приложения укажите локальную карту `http://<IPv4 компьютера>:5173`. Во вкладке «Компания» укажите тот же адрес сервера, введите имя и нажмите «Подключиться». Участники сессии видят позиции друг друга. Перед созданием группы или вступлением заполните бюджет, свободное время и желаемое место. Участники группы выделены на карте.

## Встреча группы

1. Выберите день (сегодня, завтра или послезавтра), время начала и окончания в формате `ЧЧ:ММ`. Используется время Владивостока, UTC+10.
2. Укажите личный бюджет. Ноль означает бесплатные варианты. Можно выбрать желаемое место через поиск по каталогу и до пяти интересов.
3. Нажмите «Создать группу с этими пожеланиями» либо введите код и нажмите «Вступить и отправить пожелания».
4. После вступления каждый участник редактирует свою анкету. Сервер рассчитывает пересечение свободного времени и до трёх мест. Пожелания приоритетны среди мест, прошедших ограничения по времени, бюджету и часам работы.
5. Организатор выбирает режим бюджета: каждый за себя, общий котёл или фиксированная сумма. Для фиксированной суммы подбор ждёт, пока всем хватит бюджета.
6. Организатор назначает точное время внутри общего окна и выбирает общее место. Изменения видны на всех телефонах. Если новые условия больше не допускают прежнее место или время, они перестают отображаться как согласованные.
7. «Маршрут к месту встречи» строит путь от текущей позиции конкретного участника. Можно также построить путь к предложенному или желаемому месту. После прибытия маршрут удаляется существующей логикой карты.

Точные личные суммы не включаются в список участников. Доступен общий бюджетный лимит; в режиме фиксированной суммы видно, кому её не хватает. Имена, свободное время и пожелания видны группе. Геопозиции по-прежнему видны всей LAN-сессии. Если общего времени нет или часть анкет не заполнена, показывается причина, а не произвольное место.

Подбор использует существующий `matchGroup`; оценка времени в пути приблизительная, без индивидуальных стартовых ориентиров применяется запас 25 минут. Точные пешеходные маршруты рассчитываются отдельно по кнопке. Цена и расписание каталога требуют проверки. Автоматическая отправка приглашений в мессенджеры не выполняется.

Логика режимов бюджета перенесена из `polish/demo-focus:server/src/budget.ts` в `src/social/budget.ts`. Полная серверная система аккаунтов из той ветки не требуется. Сессии используют разные публичный ID и секретный токен. Общий план меняет организатор; при его уходе полномочия переходят следующему активному участнику при обновлении сессии. Лимиты: 64 активных клиента на сервере, 16 участников группы.

После обновления кода перезапустите Vite на компьютере. Сервер хранит группы и встречи только в памяти; перезапуск удаляет их.

Адрес сервера по умолчанию определяется по адресу Metro. Его можно заменить вручную. Для доступа с телефонов порт 5173 должен быть доступен в локальной сети; гостевой Wi-Fi с изоляцией устройств не подходит.

Позиции обновляются раз в две секунды. Отключённый участник исчезает через 15 секунд. Сервер хранит сессию в памяти: перезапуск удаляет группы. Это локальная сессия без регистрации, предназначенная для доверенной сети. Координаты получают все подключённые участники. Туман и опыт остаются личными.

Каждая новая открытая ячейка даёт 1 XP, в том числе в симуляции. Повторное посещение и сброс тумана не дают повторный опыт. Награды квестов в симуляции по-прежнему не выдаются.

Меню содержит пункт «Награды» с коллекцией достопримечательностей. В нижнем меню предусмотрены квадратные места под будущие иконки.
