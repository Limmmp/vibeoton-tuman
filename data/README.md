# Данные

| Файл | Что это |
| --- | --- |
| `places.json` | каталог мест: учёба, творчество, культура, досуг, еда, прогулки. Формат — тип `Place` в [`src/data/place.ts`](../src/data/place.ts) |
| `audit.md`, `audit.json` | автоматический аудит: что убрать и что проверить руками (`npm run data:audit`) |
| `manual/overrides.json` | ручные правки поверх OSM: часы, цены, теги, `exclude`. Переживают пересборку |
| `raw/osm-places.json` | сырые кандидаты из OpenStreetMap, из них собирается `places.json` |

## Как обновлять

```bash
npm run data:fetch   # скачать свежих кандидатов из OSM (Overpass)
npm run data:build   # пересобрать places.json; проверенные и ручные записи не трогаются
npm run data:check   # проверить схему и уникальность id
npm run data:audit   # свежесть в OSM, живые ли сайты, подозрительные записи → audit.md
```

## Правила

- **`verified: true` ставит только человек**, когда сам проверил место: оно существует, часы и цена верны, теги правда (Wi-Fi, розетки, тишина). Одновременно с этим ставится `checkedAt`.
- **Правки вноси в `data/manual/overrides.json`**, а не в `places.json`: сборка применит их поверх OSM и поставит `manual: true`. Убрать место — `"exclude": true`.
- **Новое место не из OSM** добавляется вручную с собственным `id` (латиница через дефис) и ссылкой в `source`.
- **Цена «бесплатно»** у библиотек, парков и смотровых — допущение по категории, это написано в `notes`. Проверяем при верификации.
- **Коворкингов в OSM по Владивостоку нет**, их нужно добавить вручную.
